# KIRAKA Living Project Context

**Tagline:** Find help. Discover opportunity.  
**Launch Market:** Kigali, Rwanda (Initial neighborhoods: Remera, Kacyiru, Kimihurura, Nyamirambo)  
**Strategy:** PWA-first, two-sided local services marketplace  
**Core Rule:** Core marketplace is free at launch (0% commission, no paywalls). One account for both customer and provider roles.

## Key Design Principles
1. **Calm, warm, trustworthy, local:** 60-30-10 color rule. Solid brand green (#205641) is reserved for the single primary action per screen.
2. **Never color alone for status:** Every badge and status combines an icon and label.
3. **No text below 12px:** Tabular numerals for all prices and timestamps.
4. **Price is the headline:** Price appears bold and prominent on all job and offer cards.
5. **No accidental commitments:** Explicit confirmation sheets for accepting offers.
