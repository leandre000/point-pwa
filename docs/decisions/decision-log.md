# KIRAKA Project Decision Log

| ID | Date | Decision | Reason | Alternatives Considered | Consequences | Status |
|---|---|---|---|---|---|---|
| **D-001** | 2026-11-06 | PWA first, no native mobile apps in MVP | Faster iteration, single TypeScript codebase, installable where supported, low barrier to entry | Native iOS/Android via React Native or Flutter | Requires browser capability detection and graceful fallback | **Confirmed** |
| **D-002** | 2026-11-06 | One account holds both customer and provider roles | In a local economy, people both need help and offer skills; eliminates dual logins | Separate customer and provider apps | Unified profile model; role context handled via UI mode | **Confirmed** |
| **D-003** | 2026-11-06 | Core marketplace is free at launch; no paywall before value | Establish active provider supply and customer demand; PointMe 3,500 RWF fee rejected | Freemium from day 1; commission on jobs | Zero take-rate at launch; monetization deferred to Provider Pro post-pilot | **Confirmed** |
| **D-004** | 2026-11-06 | Modular monolith with Next.js, NestJS, PostgreSQL & Prisma | Maximum developer velocity, single repo contracts, transaction safety | Microservices; serverless functions only | Simple deployment; database-level transactions protect match integrity | **Confirmed** |
| **D-005** | 2026-11-06 | No escrow or holding of customer funds in MVP | Regulatory compliance; Rwanda Law No. 058/2021; payment licensing requirements | Platform escrow; cash deposit | Direct payment between parties; platform facilitates negotiation and agreement only | **Confirmed** |
| **D-006** | 2026-11-06 | Phone OTP is the primary authentication method | High smartphone phone number penetration; passwords create high friction | Email/password; social login (Google/Apple) | Requires SMS delivery adapter and rate-limiting against SMS pumping | **Confirmed** |
| **D-007** | 2026-11-11 | In-app messaging first; phone calling deferred | Lowers telco integration complexity in MVP; maintains conversation record for disputes | Masked telco calling from day 1 | Coordination happens via in-app chat after Match | **Proposed** |
| **D-008** | 2026-11-11 | Job expiry default: 72 hours; Offer expiry default: 48 hours | Keeps the marketplace liquid; prevents stale offers and unattended requests | Indefinite job validity; 24-hour rapid expiry | Background queues (BullMQ) clean up expired jobs and offers | **Proposed** |
| **D-009** | 2026-11-11 | Image upload for jobs in MVP (compressed on client); Provider portfolio in S-tier | Visual proof of repair issues increases offer accuracy | Text-only job requests; full portfolio galleries | S3-compatible signed URLs; sharp image pipeline; client-side pre-compression | **Proposed** |
| **D-010** | 2026-11-11 | Design system tokens strictly enforce WCAG AA (4.5:1 min) via CI gate | Kigali outdoor sunlight readability; accessibility baseline | Generic Tailwind defaults | Automated contrast check script fails CI if any pair drops below threshold | **Confirmed** |
| **D-011** | 2026-11-11 | Trilingual UI (English, Kinyarwanda, French) from day one | Broad adoption across diverse Kigali demographics | English-only pilot | i18n key completeness checker enforced in CI gate | **Confirmed** |
